# Fotografías de productos

Las imágenes de la tienda son fotografías referenciales de diferentes productos y marcas, no fotografías del inventario físico de NUDO. `sources.json` identifica la página de Pexels de cada fotografía y el ID del producto al que está asociada.

Las fotografías se usan y adaptan de acuerdo con la [licencia de Pexels](https://www.pexels.com/license/). `export_photos.py` permite generar de nuevo los WebP de 512 × 512 con Pillow a partir de esas fuentes.

La fotografía de portada, distinta de las imágenes de productos, procede de [Alesia Kozik en Pexels](https://www.pexels.com/photo/green-leaves-in-water-7911704/) y se ha recortado y optimizado en WebP.
